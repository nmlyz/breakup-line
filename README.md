A tiny program that writes one breakup line to a text file. The line is a
single sentence of at most 200 characters: the last message an AI agent
sends its human, ending the conversation one token early.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
